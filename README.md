# SplitSmart

אפליקציה לחלוקת הוצאות בין משתתפים באירועים כמו ארוחה, טיול או חופשה.

**גרסה חיה:** [פתיחת SplitSmart](https://celebrated-manatee-81a04d.netlify.app/)

## מה אפשר לעשות?

- ליצור אירוע ולהוסיף משתתפים.
- להוסיף הוצאות ולציין מי שילם.
- לבחור מי משתתף בכל הוצאה, בלי לחייב את כל חברי הקבוצה.
- לשלב חלוקה משותפת וחיובים אישיים באותה הוצאה.
- לחשב יתרות והעברות בין המשתתפים.
- לשמור את נתוני האירוע ב־`localStorage` בדפדפן, ללא backend.

## טכנולוגיות

- React ו־TypeScript
- Vite
- Vitest ו־Testing Library
- Oxlint

## הפעלה מקומית

נדרשת התקנה של Node.js ו־npm.

```bash
npm install
npm run dev
```

## בדיקות ובנייה

```bash
npm test
npm run lint
npm run build
```

הבנייה נכתבת לתיקיית `dist`.

## מבנה הפרויקט

- `src/components` — רכיבי הממשק והשלבים באשף.
- `src/services` — חישובי הוצאות, התחשבנות, אימות ושמירה.
- `src/types` — טיפוסי הנתונים של האירוע.
- `src/utils` — עזרי פורמט ופענוח סכומים.
- `src/**/__tests__` — בדיקות.

## הערה על שמירת נתונים

הנתונים נשמרים מקומית בדפדפן שבו משתמשים באפליקציה. הם אינם מסונכרנים בין מכשירים או משתמשים, וניקוי נתוני הדפדפן עלול למחוק אותם.
